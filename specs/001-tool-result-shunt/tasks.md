**Tests**: required (constitution II). Each slice is its failing tests, then one implementation task.

**Organization**: phases are rounds of up to 4 slices with disjoint files; a slice builds and tests

## Phase 0: Is it worth building? (round 0: S0)

### S0. Savings ceiling

- [x] T000 Measure the savings ceiling before any build work (plan D10). **Result** (maintainer, 2026-10-17): 203 qualifying results in 30 days, 1.14M tokens, 3.75% of tool-result tokens; condensed to 20% that is 0.46% of new input tokens and 0.54% of the input bill once cache re-reads are weighted (0.34% at the 50% cap). Decision: go (D10). In a scratch directory outside the repo, write an uncommitted `.mts` script run with `node --import tsx/esm` (`node -e` is blocked) that streams every `~/.claude/projects/**/*.jsonl` modified in the last 30 days line by line, pairs each assistant `tool_use` {id, name, input} with the user `tool_result` {tool_use_id, content} answering it (as T021 pairs them), and applies steps 1 to 5 of data-model.md "Eligibility" with the defaults of data-model.md "Config" (`tools`, `minLines`, `minChars`, `maxInputChars`, names matched as `toolResultTruncate.skipTools`), once as configured and once with Claude Code `Read` added (file reads included, spec Assumptions). Count tokens with `AutoTokenizer.from_pretrained('Xenova/gpt-4o')` (`@huggingface/transformers`) on LF-normalised text. Report the date, sessions read, tokenizer and, for both runs: (a) eligible tool-result tokens as a share of all tool-result tokens; (b) the ceiling, the sum over eligible results of their tokens times the assistant entries after them in the same file, as a share of those files' prompt tokens (`message.usage` `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`, each `message.id` counted once). (b) assumes every condensation is empty and detection flags nothing, so the real saving is lower. The script prints counts only, never tool output, and writes nothing under `~/.llm-fw`. Hand the figures to the owner, who decides whether Phase 1 starts. No test task: a measurement.
